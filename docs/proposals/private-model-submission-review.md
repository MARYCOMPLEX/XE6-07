# 提案：私有模型提交审核

## 动机 / 用户故事

模型所有者需要从“我的模型”提交一个私有模型供审核，但不应因提交而直接公开，也不应重复上传已有资产。

## 目标用户

- 希望发布私有模型的模型所有者
- 后续处理审核申请的管理员

## 本期范围

本期做：填写标题、描述、分类、标签和授权方式；检查封面、3D 预览、STL 或 3MF、必填字段；提交后状态变为审核中并锁定本次信息和模型版本。

本期明确不做：管理员审核或下架、公共模型库、搜索、收藏、举报、Fork、复杂版权识别、G-code 公开、多份草稿和发布历史。

## 关键决策与依据

提交审核是从私有到审核中的独立状态转换，不等于公开。模型文件、封面和预览复用已有资产；新版本不得静默替换正在审核的版本。

## 验收标准

### 例子 1：完整私有模型提交

- 现状：用户不知道发布所需信息和资源是否齐全。
- 提议后的行为：所有者填写发布信息并完成预检查。
- 验收：提交成功后模型为审核中，提交信息和版本可查看且普通用户不可见。

### 例子 2：缺失项或非所有者

- 现状：缺少文件或权限错误可能造成错误提交。
- 提议后的行为：明确展示每个缺失项，并阻断无权请求。
- 验收：缺少封面、预览、STL/3MF 或必填字段时按钮不可用；非所有者不创建申请。

### 例子 3：重复和失败请求

- 现状：重复点击或网络重试可能产生多份审核申请。
- 提议后的行为：同一模型在审核中不可再次提交，失败不改变模型状态。
- 验收：重复请求幂等；刷新和重新登录后状态仍准确。
