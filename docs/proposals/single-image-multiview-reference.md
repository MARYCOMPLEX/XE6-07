# 提案：单图生成多视图参考

## 动机 / 用户故事

单张图片缺少背面和侧面信息，直接重建容易产生不完整或不一致的结果。平台需要从单图生成结构尽量一致的多视图参考。

## 目标用户

- 以单张图片开始 3D 重建的用户
- 使用多视图输入的 3D 重建流程

## 本期范围

本期做：生成 front、left、right、back 视图；进行视角一致性控制；剔除低质量视图。

本期明确不做：替代最终 3D 重建、承诺所有图像均生成可靠背面，或定义专业人工修图工具。

## 关键决策与依据

将多视图作为重建前的独立参考层；质量不达标时阻断而非把不可靠视图伪装成可用输入。

## 待讨论

输出格式、结构一致性指标、低质量阈值、失败提示和重建阻断规则尚未确定；本提案创建后需在评审中补齐，未补齐前不视为已接受。

## 验收标准

### 例子 1：可用单图

- 现状：重建仅能猜测未出现的角度。
- 提议后的行为：生成四个方位参考并交给重建流程。
- 验收：输出包含四个命名视图；真实载荷与一致性指标为待讨论项。

### 例子 2：低质量视图

- 现状：结构矛盾的视图会污染后续重建。
- 提议后的行为：识别并剔除不达标视图。
- 验收：不得把被判低质量的视图送入重建，并返回待讨论的明确状态。

### 例子 3：不可用输入

- 现状：无法解析的图片可能进入生成流程。
- 提议后的行为：在生成前阻断。
- 验收：不创建多视图结果，不调用后续重建，并显示可理解反馈。
