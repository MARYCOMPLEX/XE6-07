# 提案：轻量网格修复与复审

## 动机 / 用户故事

当模型审计发现常见且可安全处理的问题时，用户需要能进行轻量修复，并立即比较修复是否让模型更接近可打印状态，同时保留原模型。

## 目标用户

- 上传或生成后遇到可修复网格问题的用户
- 消费审计与模型版本结果的后续流程

## 本期范围

本期做：为可修复问题提供建议和执行入口；支持补洞、法线修正、去噪和平滑、简单加厚；修复前说明影响；修复后自动复审；比较前后结论；以新的候选版本保存结果；允许接受或保留原模型。

本期明确不做：复杂网格编辑、局部雕刻、拓扑重建、人工建模、支撑、切片、真实打印，以及未经确认静默替换原模型。

## 关键决策与依据

修复产生新的候选模型版本而非覆盖原模型；可打印审计在修复后自动重新执行，避免仅凭“已修复”文案误导用户。

## 验收标准

### 例子 1：补洞和法线修正

- 现状：审计发现孔洞和法线方向问题，用户无法安全继续。
- 提议后的行为：用户看到拟处理问题并发起轻量修复。
- 验收：生成候选版本，自动复审并展示前后问题数量；用户接受后可继续使用候选版本。

### 例子 2：拒绝修复结果

- 现状：修复可能改变原模型外观或不符合用户预期。
- 提议后的行为：用户选择保留原模型。
- 验收：原版本保持可用，候选版本不替换当前使用版本。

### 例子 3：不可修复或处理失败

- 现状：失败可能被误报为成功。
- 提议后的行为：返回明确失败结果。
- 验收：不产生虚假的通过结论，不替换原版本，并展示可理解反馈。
