# 提案：人物与角色输入的姿态参考

## 动机 / 用户故事

人物或角色图姿态不统一时，直接进入 3D 重建容易出现肢体畸变、结构错误和视角不一致。系统需要在适用的输入上提供统一姿态参考。

## 目标用户

- 提交人物或角色图进行 3D 重建的用户
- 消费多视图与重建输入的后续流程

## 本期范围

本期做：人体关键点识别、姿态参考生成、标准姿态约束；非人物输入自动跳过。

本期明确不做：对非人物输入强制生成姿态、定义完整角色编辑器或替代多视图/3D 重建流程。

## 关键决策与依据

仅在识别为人物或角色的输入上启用姿态参考，避免将无关对象误送入人物规范化流程。

## 待讨论

姿态参考的输入格式、输出载荷、有效性阈值、置信度不足时的提示与后续路由尚未确定；本提案创建后需在评审中补齐，未补齐前不视为已接受。

## 验收标准

### 例子 1：人物输入

- 现状：人物姿态直接影响后续结构稳定性。
- 提议后的行为：检测到人物后生成带标准姿态约束的参考。
- 验收：后续多视图或重建模块能接收该参考；输出有效性及载荷字段为待讨论项。

### 例子 2：非人物输入

- 现状：非人物不需要姿态规范化。
- 提议后的行为：自动跳过本能力。
- 验收：非人物输入不产生姿态参考，直接保留原有后续路由。

### 例子 3：低置信度输入

- 现状：模糊或遮挡输入可能被误判。
- 提议后的行为：不得伪造有效参考。
- 验收：输出待讨论的明确失败/提示状态，不进入依赖有效姿态的后续处理。
