# 提案：复杂多色打印的颜色与耗材槽位映射

## 动机 / 用户故事

彩色模型的用户不应离开平台再手动分配颜色、AMS 槽位并检查耗材。平台需要让颜色意图转化为可追溯的实际耗材选择。

## 目标用户

- 打印彩色模型的普通用户
- 使用 Bambu AMS 或多耗材系统的用户

## 本期范围

本期做：识别颜色或部件区域；将每个区域映射到 `FilamentSlot`；校验多色能力、设备在线、已装载耗材和库存；切片与任务日志保留映射、耗材、换色废料和确认记录。

本期明确不做：3D 涂色编辑、单色模型自动上色、贴图自动转颜色区域、渐变/全彩打印、多材料力学优化和跨设备排产。

## 关键决策与依据

模型颜色仅是设计意图。提交前必须把每个 `ColorRegion` 映射到真实 `FilamentSlot`；未映射区域不得进入多色切片，避免视觉颜色与装载耗材不一致。

## 基本概念与信息结构

- `ColorRegion`：`regionId`、`source`、`displayColor`、`name`
- `FilamentSlot`：`slotId`、`printerId`、`material`、`color`、`remainingWeight`、`status`
- `ColorMapping`：`regionId`、`slotId`、`material`、`color`、`confirmedByUser`
- `MultiColorPrintProfile`：模型版本、打印机、映射、预计废料、耗时和耗材

## 验收标准

### 例子 1：全部映射后提交

- 现状：用户需在外部切片器中分配颜色。
- 提议后的行为：三个颜色区域分别映射到三个已装载且库存充足的槽位。
- 验收：校验为 `pass`；创建 `MultiColorPrintProfile`；任务日志记录映射；用户确认废料和耗时后方可提交。

### 例子 2：未映射、设备不支持或耗材不足

- 现状：风险只在提交后或外部软件中发现。
- 提议后的行为：任何阻断项都禁止多色切片。
- 验收：未映射区域、无多色能力或库存不足时按钮不可用，并显示具体区域、设备或预计克数。

### 例子 3：非法贴图输入

- 现状：只有纹理颜色的模型可能被误认为可多色打印。
- 提议后的行为：无法分离颜色区域时拒绝进入本流程。
- 验收：显示可理解的不可转换提示，不创建切片或打印任务。
